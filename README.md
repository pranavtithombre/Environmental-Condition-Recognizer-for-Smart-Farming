Environmental Condition Recognizer for Smart Farming (AI/ML)


INTRODUCTION

This project is an AI/ML-based system designed to monitor and recognize environmental conditions in agricultural fields. It analyzes parameters like temperature, humidity, and soil moisture to help farmers make better decisions for crop management.


🎯OBJECTIVES

* Monitor environmental conditions in real-time
* 
* Predict suitable farming actions (irrigation, crop suitability, etc.)
* 
* Improve crop yield using data-driven insights
* 
* Support smart farming practices
 

🧠TECHNOLOGIES USED

* Python
  
* Pandas, NumPy
  
* Matplotlib / Seaborn

* Flask / Streamlit (for dashboard)


 📊 Dataset
 
The dataset includes environmental parameters such as:

* Temperature
  
* Humidity
  
* Soil MoisturE
  
* Rainfall
  
* Light intensitY
  
*Dataset Source:*

* Kaggle / Custom sensor data


🔍 Features

* Data collection and preprocessing
 
* Environmental condition classification
 
* Crop recommendation system

* Irrigation suggestion (e.g., when to water crops)
  
* Data visualization dashboard


RESULTS
